lean_os

A desktop operating system written from scratch, running somebody else's browser.

This page is served from this machine's own disk at /usr/share/browser/home.html, laid out by Blink, drawn by Skia, and composited into a window the desktop owns.

Type an address into the bar above and press Enter. google.com is a reasonable first try; it will take a few seconds.

The terminal, the editor, the file manager and this browser's window chrome are first-party. The engine is not, and none of its source was edited to get here.
